# Joy-Full Everyday — Sales Page Concepts

Static concept mockups for the Joy-Full Everyday daily gummy pack.

- `index.html` — chooser page linking the three options
- `option-a-omni.html` — Option A: Omni-style flow (quiz, benefit tabs, Us vs. Them)
- `option-b-gruns.html` — Option B: Grüns-style flow (price-led hero, "how many adults?" buy box)
- `option-c-hybrid.html` — Option C: hybrid, recommended (value vs. buying each complex separately)
- `story/` — formula storyboard (finalized v9 formula, four complexes, cost comparison) plus PDF versions
- `shared/data.js` — all prices and copy in one place; edit here to update every page

**Concept mockup only.** Prices, guarantee, shipping, countdown and review slots are demo placeholders. No checkout is connected. Competitor prices were taken from brand sites (Nov 2026) and compare price, not dose for dose.

Pages are marked `noindex` so search engines skip them.
